# Password-Analyser

A Python-based tool designed to automate the analysis phase of Active Directory password audits.

Developed as a Proof of Concept to accompany [Password Audits Part 4: Analysing Results](https://mollysec.com/posts/password-audits-part-4/).

It consumes recovered password datasets and supporting artefacts generated by [`ntds-organiser`](https://github.com/CSpanias/ntds-organiser) and produces statistics, evidence tables, executive summaries, technical commentary, and remediation guidance in Markdown format.

## Installation

Recommended (`uv`):

```bash
# Install UV
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install password-analyser via UV
uv tool install git+https://github.com/CSpanias/password-analyser

# Verify installation
password-analyser -h

# Update
uv tool upgrade password-analyser
```

Clone locally:

> Note: Python 3 must be installed and available in your `PATH`.

```bash
# Clone the repository
git clone https://github.com/CSpanias/password-analyser /opt/password-analyser

# Make the script executable
chmod +x /opt/password-analyser/password_analyser.py

# Create a symbolic link
sudo ln -s /opt/password-analyser/password_analyser.py /usr/local/bin/password-analyser

# Verify installation
password-analyser -h
```

## Features

The tool focuses on transforming recovered passwords into findings that can support reporting and remediation efforts.

### Dataset Analysis

* Calculate overall password recovery statistics
* Identify recovered privileged accounts
* Identify passwords that violate the configured password policy
* Identify password reuse between related accounts
* Identify username-derived passwords
* Identify organisation-related passwords
* Identify date-related passwords
* Identify keyboard walk patterns
* Identify common password terms and variants
* Analyse character class adoption
* Analyse password length distribution

### Reporting

* Generate Executive Summary, Technical Commentary, and Remediation Guidance in Markdown format
* Generate evidence tables for identified findings

## Usage

```bash
# Help menu
$ password-analyser -h
usage: password-analyser [-h] -M MAPPED_PASSWORDS [-A DOMAIN_ADMINS] [-P PASS_POLICY] [-C COMPANY_WORDS] [-E ENABLED_USERS]

Password Audit

options:
  -h, --help            show this help message and exit
  -M, --mapped-passwords MAPPED_PASSWORDS
                        mapped-passwords.txt
  -A, --domain-admins DOMAIN_ADMINS
                        domain-admins.txt (default: ./ntds-organiser/domain-admins.txt)
  -P, --pass-policy PASS_POLICY
                        domain-policy.txt (default: ./ntds-organiser/domain-policy.txt)
  -C, --company-words COMPANY_WORDS
                        File containing company-related words
  -E, --enabled-users ENABLED_USERS
                        enabled-users.txt (default: ./ntds-organiser/enabled-users.txt)

# Basic Analysis
password-analyser -M mapped-passwords.txt

# Include Company-Specific Keywords
password-analyser -M mapped-passwords.txt -C company-words.txt

# Full Workflow
password-analyser -M mapped-passwords.txt -A domain-admins.txt -P domain-policy.txt -E enabled-users.txt -C company-words.txt
```

## Example Output

```bash
password-analyser -M mapped-passwords.txt -A domain-admins.txt -P domain-policy.txt -E enabled-users.txt -C company-words.txt

[+] Executive Summary, technical commentary, and remediation guidance generated.
[+] Output: results.md
```
